# V3 재설계 2차 — 이동 회색박스

## 목적

최종 그래픽을 만들기 전에 조작감과 첫 세 방의 플레이 가능성을 독립적으로 검증한다. 기존 V2의 갑작스러운 이동, 불안정한 벽·경사 상호작용, 카메라의 거친 전환을 반복하지 않도록 물리 수치를 먼저 고정한다.

## 실행

저장소 루트에서 정적 파일 서버를 연 뒤 `v3.html`에 접속한다.

```text
python -m http.server 8000
http://localhost:8000/v3.html
```

조작은 `A/D` 이동, `Space` 가변 점프 및 이중 점프, `R` 재시작이다. 기존 공개 빌드인 `index.html`은 변경하지 않았다.

## 구현 범위

- `r01 도착 전실`: 안전한 이동, 가속, 감속, 낮은 단차
- `r02 도약 공방`: 점프 입력 시간에 따른 높이 차이와 안전 발판
- `r03 공명 날개 제단`: 이중 점프 획득, 두 단계 상승, 회복 착지대
- 120Hz 고정 물리 업데이트
- 코요테 타임 0.11초
- 점프 입력 버퍼 0.12초
- 상승 중 입력 해제에 따른 짧은 점프
- 접지 시 점프 횟수 초기화
- 카메라 감쇠 이동과 진행 방향 미리보기
- 먼 배경 0.12배, 중간 배경 0.28배의 회색박스 시차 이동

- 콘솔 및 페이지 오류: 0건
