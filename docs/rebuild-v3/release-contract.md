# V3 40차 출시 계약

## 최종 완료 기준

40차의 목적은 작업 횟수를 채우는 것이 아니다. 튜토리얼과 첫 번째 초대형 방 전체를 처음부터 끝까지 실제로 플레이할 수 있고, 공개 사이트에서 바로 실행되는 출시 후보 상태로 만드는 것이 완료 기준이다.

다음 조건을 모두 충족하지 못하면 40차 완료로 기록하지 않는다.

- 이동, 점프, 이중 점프, 벽 점프, 대시, 집게, 공격이 정상 작동한다.
- 튜토리얼은 설명 없이 막히지 않으며 새 기능을 안전한 상황에서 하나씩 가르친다.
- 첫 3개 방 안에서 주인공이 누구인지, 무엇이 결핍되었는지, 왜 근원으로 가야 하는지가 플레이 중 명확해진다.
- 모든 핵심 능력은 이야기상 회수하는 기능 기억이며, 획득 직후 그 능력이 필요한 상황이 이어진다.
- 공격 능력을 얻기 전에는 강제 전투가 없고, 이후 적은 역할·위험·서사적 원인이 함께 단계적으로 강해진다.
- 15번 방에서 근원 수호자와 원점 코어에 도달하고, 시작 목표와 핵심 진실이 실제 결말로 회수된다.
- 15개 공간이 5개 층의 지그재그 경로로 연결되고, 단순 직선 복도가 반복되지 않는다.
- 각 방은 다른 판단과 리듬을 요구하며, 같은 장애물 조합을 연속 사용하지 않는다.
- 적은 역할과 대응 방식이 다른 종류로 구성되고, 동시에 활성화되는 적은 최대 3개다.
- 추격석은 실제 지면을 따라 움직이며 화면 아래나 공중에서 따로 움직이지 않는다.
- 카메라 전환, 체크포인트, 재시작, 저장, 입력 안내, 성능이 실제 공개 플레이에 적합하다.
- 최종 그래픽, 캐릭터 모션, 전경·중경·배경 시차, 명암, 구조물 지지가 적용된다.
- 첫 화면 접속만으로 게임이 실행되고, 전체 무중단 검사와 수동 플레이 검토를 통과한다.

## 차수 배분

| 구간 | 목적 | 완료 조건 |
|---|---|---|
| 1~5차 | 구조·기본 조작 기반 | 지그재그 15방 청사진, 이동감, 벽, 경사 물리 확정 |
| 6~10차 | 튜토리얼과 초반 본 경로 | 1~7번 방 통합, 능력 학습과 선택 경로 검증 |
| 11~16차 | 중반 공간과 전투 | 8~12번 방, 역할이 다른 적, 압착기·승강고·집게 조합 |
| 17~21차 | 후반과 결말 | 13~15번 방, 지면 추격, 수호자, 출구까지 전체 회색박스 완주 |
| 22~27차 | 조작·난도·동선 개선 | 막힘, 과도한 정밀도, 반복, 카메라, 체크포인트 제거 및 조정 |
| 28~35차 | 최종 시각·음향 제작 | 캐릭터·적 모션, 환경 그래픽, 시차, 명암, 효과음·음악 적용 |
| 36~38차 | 출시 기능과 최적화 | 메뉴, 저장, 접근성, 로딩, 브라우저 성능, 다양한 화면 크기 |
| 39차 | 전체 출시 후보 검증 | 처음부터 끝까지 수동·자동 무중단 검사, 결함 수정 |
| 40차 | 공개 사이트 완성 | 접속 즉시 실행, 최종 증거와 배포 상태 확정 |

## 이야기 승인 규칙

이야기는 별도의 설명문이 아니라 플레이 진행의 원인이어야 한다.

1. 필수 정보는 정상 진행 경로에서 전달하며 숨겨진 수집품에만 맡기지 않는다.
2. 새 능력, 새 적, 새 장애물은 직전 사건의 결과로 등장한다.
3. 기록은 다음 목표를 구체적으로 갱신해야 하며 이미 지나간 내용을 반복하지 않는다.
4. 몬스터는 검은 공명에 변형된 관리체라는 공통 원인을 가지되, 역할과 대응 방식은 단계마다 달라야 한다.
5. 최종 반전은 앞선 기록과 환경 단서로 예고하고, 마지막 한 장면에서 갑자기 추가하지 않는다.
6. 컷신이나 기록장을 건너뛰어도 조작은 가능해야 하지만 현재 목표는 HUD에서 항상 확인할 수 있어야 한다.

## 구조물 승인 규칙

경사, 다리, 발판, 기둥, 함정, 레일, 장식 구조는 다음 질문 중 하나에 명확히 답해야 한다.

1. 무엇을 가르치는가?
2. 어떤 선택을 만들거나 어떤 위험을 예고하는가?
3. 전투나 이동에서 어떤 새로운 대응을 요구하는가?
4. 실패했을 때 어디로 회수하는가?
5. 공간의 방향과 다음 목표를 어떻게 읽게 하는가?

어느 질문에도 답하지 못하는 구조물은 삭제하거나 역할이 생기도록 다시 설계한다. 첫 학습 구간에는 즉사 위험을 두지 않고, 정밀 입력은 숙련 선택 경로에만 사용한다.
