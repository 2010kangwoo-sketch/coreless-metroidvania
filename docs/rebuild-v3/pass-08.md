# V3 재설계 8차 — 이야기 기반과 플레이 가능한 프롤로그

## 이번 차수의 목적

앞선 회색박스는 이동과 층 구조를 검증했지만, 주인공이 왜 움직이고 능력을 왜 얻는지 명확하지 않았다. 8차에서는 방을 하나 더 늘리는 대신 15개 방 전체의 이야기 인과관계를 먼저 고정하고, 현재 플레이 가능한 R01~R04에 실제 프롤로그·기억 기록·목표 갱신을 적용했다.

## 확정된 줄거리

기억과 중심 코어가 분리된 `코어리스`가 폐쇄된 제련소에서 깨어난다. 위층의 `원점 코어`가 주인공만 알아들을 수 있는 신호를 보내고, 코어리스는 각 구역에 흩어진 기능 기억을 되찾으며 근원으로 향한다.

원점 코어에서 새어 나온 `검은 공명`은 관리 기계와 생체 잔재를 점점 강한 괴물로 변형한다. 중반에는 코어 분리가 사고가 아니라 폭주를 막기 위한 주인공 자신의 선택이었음이 드러난다. 마지막에는 근원 수호자를 쓰러뜨리고, 자신에게서 분리된 중심인 원점 코어의 역류를 기억을 지우지 않은 채 안정화한다.

## 실제 플레이에 적용한 내용

- 시작 시 프롤로그: 주인공, 결핍, 첫 목표, 최종 방향 제시
- `Tab` 기억 기록장: 발견한 사건만 순서대로 복원
- HUD 현재 목표: 프롤로그를 넘겨도 진행 이유를 계속 표시
- R01 잔향: 원점 신호가 주인공을 알고 있음을 암시
- R02 분리 기록: 기능 기억이 여러 구역에 봉인되었음을 설명
- R03 공명 날개: 이중 점프를 새 장비가 아니라 되찾은 기억으로 연결
- R03→R04 실제 승강: 상층에서 원점 신호 증폭
- R04 검은 흔적: 다음 구역의 휴면 파수기와 위험을 예고

## 15방 진행 계약

- 5장, 각 장 3개 방
- 여섯 능력은 R01, R03, R05, R06, R07, R08 순서로 회수
- 공격 획득 전인 R01~R07에는 필수 전투 없음
- R08부터 역할이 다른 적이 단계적으로 증가
- R11에서 자발적 코어 분리의 진실 공개
- R13에서 원점 코어가 주인공의 중심임을 확인
- R15에서 근원 수호자·원점 코어·시작 목표를 모두 회수

세부 계약은 `docs/rebuild-v3/story-spec.md`에 기록했다.

## 시각 검수에서 발견하고 수정한 문제

첫 브라우저 실행에서 프롤로그 제목과 목표는 보였지만 Canvas의 비표준 글꼴 굵기 처리로 본문과 기록 설명이 표시되지 않았다. 호환되는 글꼴 굵기로 바꾼 뒤 프롤로그 네 줄, 기록 제목과 설명, 복귀 안내를 다시 직접 확인했다.
