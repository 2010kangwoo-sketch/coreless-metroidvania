# V3 재설계 3차 — 조작감 확정

## 목적

2차에서 만든 이동·점프의 기본 수치를 유지하면서 방향 전환, 공중 제어, 착지 직전 입력, 단차 모서리, 수직 카메라 움직임을 다듬는다. 방이나 그래픽을 늘리지 않고 플레이어가 버튼 입력의 결과를 예측할 수 있는지를 먼저 검증한다.

## 변경 내용

### 방향 전환

- 일반 지상 가속과 반대 방향 회전 가속을 분리했다.
- 달리다가 반대 방향을 누르면 0.225초에 정지점을 지난다.
- 반대 방향 최고 속도의 90%까지 0.425초에 도달한다.
- 회전 중 속도가 0을 지났다고 일반 가속으로 조기에 돌아가지 않는다.

### 공중 제어

- 공중에서 입력하지 않을 때 0.5초 뒤 수평 관성의 78.6%를 보존한다.
- 공중 반대 입력은 지상 반전보다 느리게 적용한다.
- 0.25초 반대 입력으로 속도가 320px/s만큼 변해 방향 수정은 가능하지만 즉시 역전되지는 않는다.
- 점프 최고점 부근의 중력을 0.86배로 낮춰 궤적이 급하게 꺾이지 않게 했다.

### 착지와 모서리

- 착지 직전 0.12초 안에 들어온 점프 입력은 착지 뒤 즉시 실행한다.
- 착지 순간의 수평 방향 입력도 함께 보존한다.
- 단차 모서리 보정은 최대 10px로 제한했다.
- 결정적 검사에서 필요한 보정량은 1px였으며, 10px를 넘는 자동 상승은 차단됐다.
- 벽에 비비는 것만으로 높은 바닥 위로 솟아오르는 방식은 사용하지 않는다.

### 카메라와 모션

- 수직 데드존을 64px로 설정해 작은 점프마다 화면이 따라 흔들리지 않게 했다.
- 수직 카메라 반감기는 0.16초로 수평 카메라 0.10초보다 느리다.
- 실제 점프 중 카메라 Y 변화 범위는 5.06px였다.
- 출발 순간에는 짧은 세로 늘림, 착지 순간에는 0.14초의 짧은 눌림을 적용했다.
- 이는 최종 캐릭터 애니메이션이 아니라 모션 타이밍 확인용 회색박스 변형이다.

## 검사 결과

### 결정적 물리 검사

- 통과: 25/25
- 지상 반전 90% 도달: 0.425초
- 공중 반전 90% 도달: 0.625초
- 공중 관성 보존: 78.6%
- 모서리 보정: 1px
- 수직 카메라 첫 이동: 고정 프레임당 4.255px
- 수직 카메라 최종 오차: 0.02px

### 실제 키보드 브라우저 검사

- 통과: 19/19
- 실제 전진 속도: 420px/s
- 실제 반전 속도: -420px/s
- 공중 반대 입력 전후: 420px/s → 78.67px/s
- 착지 버퍼 재점프 속도: -525.25px/s
- 점프: 16회
- 이중 점프: 2회
- 착지: 14회
- 첫 세 방 완주 최종 위치: `(4762, 656)`
- 전체 경로 중 추가 리셋: 0회
- 콘솔 및 페이지 오류: 0건
