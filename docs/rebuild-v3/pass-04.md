# V3 재설계 4차 — 벽 이동 확정

## 목적

기존 버전에서 벽에 비비기만 해도 캐릭터가 갑자기 위로 솟구치던 문제를 되풀이하지 않고, 벽 미끄럼과 벽 점프만으로 예측 가능한 수직 이동을 만든다. 본 경로에 바로 넣지 않고 독립된 회색박스 시험실에서 물리와 실제 입력을 먼저 검증한다.

## 적용 범위

- 별도 시험 페이지: `v3-wall-test.html`
- 본 경로 여부: 비정규 개발 시험실
- 최종 그래픽: 포함하지 않음
- 조작: `A/D` 이동, `Space` 점프, `R` 재시작
- 기존 `v3.html`의 1~3번 방 구조는 변경하지 않음

## 벽 이동 규칙

### 벽 접촉과 미끄럼

- 캐릭터의 좌우 3px 안에 `wall` 역할의 지형이 있을 때만 벽 접촉으로 인정한다.
- 벽에 닿은 채 떨어질 때 하강 속도를 170px/s로 수렴시킨다.
- 방향키만 벽 쪽으로 누르는 동안에는 위쪽 속도를 만들지 않는다.
- 일반 발판이나 장식은 벽 점프 표면으로 오인하지 않는다.

### 벽 점프

- 벽 점프 수평 속도: 390px/s
- 벽 점프 수직 속도: 680px/s
- 벽을 떠난 뒤 입력 허용 유예: 0.10초
- 같은 벽에 즉시 다시 붙는 것을 막는 시간: 0.12초
- 점프 입력이 없으면 벽 접촉만으로 점프하거나 올라가지 않는다.

### 모서리와 회복 발판

- 벽 역할 지형에는 모서리 자동 상승 보정을 적용하지 않는다.
- 따라서 벽 꼭대기 근처에서 캐릭터가 갑자기 위로 올라가는 방식은 차단된다.
- 중간 회복 발판은 아래에서 통과하고 위에서만 착지하는 단방향 발판이다.
- 200px 폭의 일정한 샤프트와 세 개의 휴식 발판으로 초보자도 리듬을 다시 잡을 수 있다.
- 최상단은 오른쪽 벽을 넘은 뒤 넓은 출구 발판에 착지하도록 구성했다.
