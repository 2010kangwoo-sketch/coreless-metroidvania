# V3 이야기 설계 기준

## 한 문장 줄거리

기억과 중심 코어를 잃은 `코어리스`가 폐쇄된 제련소에서 기능 기억을 하나씩 되찾고, 검은 공명에 변형된 관리체를 돌파해 자신에게서 분리된 `원점 코어`에 도달하는 이야기다.

## 플레이어가 알아야 하는 핵심

| 항목 | 확정 내용 | 전달 시점 |
|---|---|---|
| 주인공 | 기억도 중심도 없이 깨어난 존재 `코어리스` | R01 프롤로그 |
| 첫 목표 | 위쪽에서 들리는 원점 코어의 신호 추적 | R01 |
| 능력의 정체 | 새 장비가 아니라 과거에 분리해 둔 기능 기억 | R03부터 반복 확인 |
| 몬스터의 정체 | 검은 공명에 잠식된 시설 관리 기계와 생체 잔재 | R04 예고, R08 확인 |
| 중반 진실 | 코어 분리는 사고나 타인의 공격이 아니라 주인공 자신의 선택 | R11 |
| 최종 진실 | 원점 코어는 외부의 물체가 아니라 주인공에게서 분리된 중심 | R13 |
| 결말 목표 | 근원 수호자를 쓰러뜨리고 기억을 지우지 않은 채 역류 안정화 | R15 |

## 5장·15방 전개

| 장 | 방 | 이야기 변화 | 플레이 변화 |
|---|---|---|---|
| 1장 빈 중심의 각성 | R01~R03 | 결핍과 원점 신호를 발견한다 | 이동·점프·이중 점프 회수 |
| 2장 잠긴 제련소 | R04~R06 | 오염 흔적과 시설 봉쇄를 마주한다 | 경사·집게·대시 |
| 3장 적이 된 기록 | R07~R09 | 관리체가 괴물이 된 원인을 확인한다 | 벽 이동·공격·첫 역할 전투 |
| 4장 분리 명령의 진실 | R10~R12 | 주인공이 스스로 코어를 분리했음을 알게 된다 | 복합 장애물·능력 조합 |
| 5장 원점으로의 귀환 | R13~R15 | 원점 코어와 수호자의 정체를 확인한다 | 최종 추격·수호자·결말 |

## 능력 회수 순서

| 방 | 기능 기억 | 실제 역할 | 이야기 이유 |
|---|---|---|---|
| R01 | 비상 기동 회로 | 이동·점프 | 중심 없이 남은 최소 생존 기능 |
| R03 | 공명 날개 | 이중 점프 | 공명 출력을 두 단계로 나누는 기억 |
| R05 | 연결사 기억 | 집게 | 시설 레일을 수리하던 연결 권한 |
| R06 | 맥동 추진기 | 대시 | 봉쇄 수문을 통과하는 압축 공명 |
| R07 | 벽면 고정각 | 벽 이동 | 상승축 유지보수 기록 |
| R08 | 절단 권한 | 공격 | 관리체를 해치지 않기 위해 봉인했던 전투 권한 |

공격 기억은 첫 강제 전투 직전에만 열린다. R01~R07에는 위협 예고와 회피는 있어도 필수 처치를 두지 않는다.

## 적의 단계

| 단계 | 방 | 적 역할 | 학습 목표 |
|---:|---|---|---|
| 0 | R04~R07 | 흔적·휴면 파수기·회피형 매복체 | 위험을 읽고 피하기 |
| 1 | R08 | 지상 크롤러 | 기본 공격과 거리 조절 |
| 2 | R08~R09 | 비행 파수기·고정 포탑 | 높이와 엄폐 |
| 3 | R10~R11 | 장갑 경비체·강화 크롤러 | 약점 노출 주기와 공격 순서 |
| 4 | R12~R14 | 천장 매복체·붕괴 방어체 | 이동 능력과 전투 조합 |
| 5 | R15 | 근원 수호자 | 모든 능력과 안전한 반격 창 |

동시에 활성화되는 적은 최대 3개로 제한한다. 화면 밖 공격, 읽을 수 없는 즉시 공격, 실패 후 장거리 재이동은 허용하지 않는다.

## 현재 8차에서 실제 구현된 사건

1. R01 프롤로그에서 코어리스·결핍·원점 코어 목표를 제시한다.
2. R01 이동 중 신호가 주인공을 알고 있다는 잔향을 듣는다.
3. R02에서 기능 기억이 각 구역에 분리됐다는 기록을 발견한다.
4. R03 이중 점프를 `공명 날개` 기억의 회수로 설명한다.
5. 승강기를 타고 실제 상층 R04에 도착하면 원점 신호가 강해진다.
6. R04 서쪽에서 검은 공명의 긁힌 흔적과 다음 방의 파수기를 예고한다.

`Tab`으로 현재 발견한 기억 기록을 열 수 있고, 필수 목표는 HUD에 계속 표시된다.
