# V3 재설계 7차 — 실제 2층 지그재그 전환

## 먼저 확인한 문제

6차까지는 화면과 진행 상태가 1~3번 방으로 나뉘었지만, 실제 월드는 높이 900px 안에서 세 방이 같은 Y좌표에 놓인 가로 구조였다. 따라서 당시 구현을 “층층이 나뉜 초대형 방”이라고 볼 수 없었다.

7차에서 월드 높이를 2,040px로 확장하고, 아래층 1~3번 방과 위층 4번 방을 실제 충돌 좌표에서도 분리했다. 현재 플레이 가능한 범위는 최종 5층 청사진 중 **첫 2층·4개 방**이다. 나머지 3층은 후속 차수에서 같은 지그재그 규칙으로 추가한다.

## 실제 층 배치

| 층 | Y 범위 | 방 | 진행 방향 |
|---|---:|---|---|
| 위층 2/5 | 0~900 | R04 완경사 회랑 | 서쪽 |
| 구조 간격 | 900~1,140 | 시야·승강축 공간 | 수직 |
| 아래층 1/5 | 1,140~2,040 | R01 도착 전실 → R02 도약 공방 → R03 공명 제단 | 동쪽 |

R03과 R04는 같은 X범위 `3,200~4,800`에 위아래로 포개져 있다. R03 동쪽 착지대의 승강기가 플레이어를 770px 연속 상승시킨 뒤 R04 동쪽에 내려놓고, 진행 방향이 서쪽으로 바뀐다.

## 4번 방의 구조물 목적

- 동쪽 도착대 320px: 승강기에서 내린 뒤 방향을 바꿀 준비 공간
- 완경사 480px: 서쪽으로 이동하면서 오르막 속도 변화를 처음 확인
- 정상 정지대 240px: 급경사에 들어가기 전에 멈추고 아래 동선을 읽는 공간
- 급경사 300px: 입력을 놓았을 때 서쪽으로 자연스럽게 미끄러지는 구간
- 서쪽 회수·출구대 260px: 과속을 회수하고 다음 방을 준비하는 공간
- 승강 레일 2개: Y=700부터 Y=1,900까지 이어져 화면 아래에서 지지대가 잘린 것처럼 보이지 않음

피해 장애물과 적은 넣지 않았다. 첫 층 전환과 경사 조작을 동시에 배우는 구간이므로 실패 비용을 추가할 이유가 없다.

## 불친절성 수정

첫 브라우저 검사에서 다음 문제를 발견해 수정했다.

1. 승강기가 상단 착지 전 공중 또는 아래 바닥에서 작동하던 문제

   → 상단 착지대에 서 있을 때만 작동하도록 판정 높이를 제한했다.
2. 마지막 착지대가 250px라 실행 편차에 따라 놓칠 수 있던 문제

   → 366px로 넓혔다.
3. 착지대를 놓치면 오른쪽에서 다시 올라오기 어려운 문제

   → 아래에서 통과하고 위에서 착지하는 회수 발판 두 개를 추가했다.
4. 아래층 카메라가 시작 직후 한 프레임에 약 44px 보정되던 문제

   → 카메라를 처음부터 현재 층 높이에 배치했다.
5. 서쪽 출구가 너무 일찍 판정되던 문제

   → 출구 폭을 210px에서 80px로 줄여 회수대 끝까지 이동하게 했다.

## 배경과 카메라

- 먼 배경 이동 비율: X 0.12, Y 0.08
- 중간 배경 이동 비율: X 0.28, Y 0.16
- 지형 이동 비율: X 1.00, Y 1.00

따라서 캐릭터와 지형이 움직일 때 먼 배경이 가장 느리게 움직이고, 중간 배경이 그다음으로 움직인다. 수직 승강에서도 같은 시차가 적용된다.

## 다음 차수

8차는 같은 위층에서 서쪽으로 이어지는 R05 진자 집게실을 실제 좌표에 연결한다. 집게는 단순 장식이나 자동 이동이 아니라, 해제 시점에 따라 세 개의 넓은 착지대 중 하나를 선택하는 구조로 만든다. 실패해도 아래 회수 통로와 재도전 동선으로 즉시 돌아오게 하며, R04 경사 출구에서 R05 진입까지 무중단 검사를 유지한다.
