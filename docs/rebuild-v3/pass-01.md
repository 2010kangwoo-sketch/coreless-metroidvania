# V3 재설계 상세 1차

## 목표

기존 40차 결과의 직선적 공간 구성과 반복 장애물을 답습하지 않고, 실제 플레이를 먼저 검증할 수 있는 지그재그 초대형 방 청사진을 확정한다.

## 완료한 내용

- 5층 × 3방의 15개 본방 설계
- 층마다 동·서 방향이 바뀌는 지그재그 주 경로
- 14개 필수 연결과 4개 교대 상승축
- 3개 선택 옆방, 3개 해금 지름길, 7개 체크포인트
- 15개 서로 다른 핵심 메커니즘
- 6개 적 역할과 최대 동시 활성 적 3개 제한
- 각 방의 3단계 플레이 비트, 선택, 실패 회수, 다음 방 예고
- 7개 능력의 도입 방과 후속 재사용 위치
- 59종 구조물 기능 정의
- 15방 전체 긴장도 곡선과 5개 페이싱 장

## 정량 결과

- 예상 플레이 시간: 1,150초, 약 19분 10초
- 방 역할: 13종
- 고유 메커니즘: 15종
- 고긴장 연속 상한: 2방
- 결정적 설계 검사: 51/51 통과
