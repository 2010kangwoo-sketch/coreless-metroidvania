# V3 재설계 5차 — 경사 이동 확정

## 목적

기존 버전에서 경사 위 위치가 갑자기 변하고, 급경사에서도 캐릭터가 평지처럼 완전히 멈추던 문제를 다시 만들지 않는다. 경사의 표면 높이를 고정 프레임마다 계산해 완경사 이동, 점프 재착지, 평지 제동, 급경사 미끄럼을 독립 시험실에서 먼저 검증한다.

이 경사들은 최종 방을 채우기 위한 장식이 아니다. 4번 방에서 속도 선택과 제동을 가르치기 위한 기반이며, 역할 없는 경사는 본 경로에 추가하지 않는다.

## 시험실 구조

| 구조 | 역할 |
|---|---|
| 첫 완경사 | 오르막 속도와 연속 접지 학습 |
| 300px 정상 평지 | 입력 해제 뒤 정지 확인 |
| 급경사 내리막 | 입력을 놓았을 때의 제한적 미끄럼 학습 |
| 420px 하단 평지 | 과속 회수와 다음 행동 준비 |
| 회복 완경사 | 같은 규칙이 반복 상황에서도 예측 가능한지 확인 |
| 420px 출구 평지 | 안전한 완료 착지 |

피해 장애물과 적은 포함하지 않았다. 새 물리를 처음 배우는 구간이므로 실패 비용을 만들 이유가 없기 때문이다.

## 경사 물리

- 경사 발밑 높이는 사각형 충돌이 아니라 선형 표면식으로 계산한다.
- 완경사 기울기: 0.25
- 급경사 기울기: 0.60
- 경사 접지 허용 오차: 8px
- 오르막 목표 속도: 평지의 0.82배
- 내리막 입력 목표 속도: 평지의 1.05배
- 완경사 입력 해제 감속: 1,400px/s²
- 급경사 입력 해제 미끄럼 상한: 280px/s
- 점프 중에는 경사 접지를 해제하고, 위에서 내려올 때만 다시 착지한다.
- 경사와 연결 평지 사이에서는 수평 모서리 보정을 사용하지 않는다.
