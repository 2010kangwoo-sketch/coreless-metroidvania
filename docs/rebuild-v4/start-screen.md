# Coreless V4 시작 화면

## 목적

게임을 실행하면 개발용 회색박스 화면이 바로 노출되지 않고, 세계관과 저장 상태를 보여주는 정식 시작 화면을 먼저 표시한다. 최종 배경 원화가 확정되기 전에도 사용할 수 있도록 HTML·CSS 기반의 가벼운 화면으로 제작했다.

## 시각 구성

- 왼쪽에는 `CORELESS` 제목과 실제 메뉴를 배치한다.
- 오른쪽에는 빈 제련소 아치, 원점 코어, 코어리스 실루엣을 배치한다.
- 원경 아치, 중경 구조물, 전경 바닥을 분리해 깊이를 만든다.
- 원점 코어의 호흡, 부유, 먼지는 느리고 작은 범위로 제한한다.
- 선택되지 않은 메뉴는 낮은 명도로 두고 현재 선택만 청록 프레임과 금빛 보조 정보로 강조한다.
- `prefers-reduced-motion` 환경에서는 반복 애니메이션과 긴 전환을 제거한다.

현재 화면은 최종 배경 원화를 대신하는 임시 회색박스가 아니라, 최종 미술을 교체하기 전까지 사용할 수 있는 코드 기반 시작 화면이다. 추후 본편의 확정 팔레트와 캐릭터 원화가 나오면 구조와 메뉴 동작은 유지하고 배경층만 교체할 수 있다.

## 실제 메뉴

### 이어하기

검증된 V4 저장 기록이 있을 때만 활성화된다. 버튼 아래에 `S35 · 6층 체크포인트`처럼 실제 저장 위치를 표시한다. 손상된 저장, 미래 버전 저장, 존재하지 않는 체크포인트는 이어하기에 사용하지 않는다.

### 새 게임

저장 기록이 없으면 바로 S01에서 시작한다. 기존 기록이 있으면 확인창을 표시하고, 사용자가 `새로 시작`을 선택한 경우에만 기록을 S01로 초기화한다.

### 조작 안내

현재 실제로 존재하는 이동, 가변 점프, 상호작용, 기록, 체크포인트 복귀만 안내한다. 아직 구현하지 않은 스킬이나 작동하지 않는 설정 메뉴를 표시하지 않는다.

## 입력

- `W/S` 또는 `↑/↓`: 메뉴 선택
- `Enter` 또는 `Space`: 확인
- `Escape`: 조작 안내·확인창 닫기
- 마우스 클릭과 키보드 포커스 모두 지원

시작 화면이 열린 동안 본편 런타임은 입력과 시간을 진행하지 않는다. 메뉴가 닫힌 뒤에만 게임 루프를 시작하고 캔버스로 포커스를 넘긴다.
