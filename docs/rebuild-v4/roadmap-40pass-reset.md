## 차수 운영 규칙

1. 차수 하나는 작업 목록이 아니라 확인 가능한 결과 하나를 완성한다.
2. 완료 조건이 실패하면 차수 번호를 올리지 않는다.
3. 집중 검사는 해당 기능만 빠르게 재현한다.
4. 통합 검사는 이전 기능과 연결된 실제 플레이를 확인한다.
5. 10·20·30·40차에는 자동 검사와 별도로 사용자 실제 플레이 승인이 필요하다.
6. 좌표 주입으로 전체 완주를 대신하지 않는다.
7. 그래픽은 34차 전까지 구조 판독용으로 제한하고, 조작·공간 문제가
   최종 아트에 가려지지 않게 한다.
8. 40차가 끝나도 M02~M20을 완성했다고 표시하지 않는다.
