# Coreless V4 첫 초대형 방 규모 계약

## 왜 다시 시작하는가

V3의 15개 공간은 층별 지그재그 구조를 확인하는 데에는 유효했지만, 공간 하나가 짧고 전체 이동량이 부족해 실제 플레이에서 빠르게 지나갈 가능성이 컸다. V4에서는 초대형 방의 최소 규모와 시간부터 다시 정의한다.

## 확정 규모

| 항목 | V4 기준 |
|---|---:|
| 기준 화면 | 1,400 × 900px |
| 공간 하나 | 약 2화면 면적 |
| 한 층 | 6개 공간 |
| 초대형 방 | 6층 × 6공간 = 36공간 |
| 공간 평균 목표 | 20초 |
| 초대형 방 목표 | 720초 = 12분 |
| 기준 월드 | 16,800 × 7,400px |
| 전체 게임 | 20개 초대형 방·720공간·240분 |

첫 초대형 방을 포함해 총 20개일 때 `20 × 12분 = 240분`이다. 첫 방 뒤에 20개를 더 만들면 총 21개·252분이 되므로, 현재 4시간 계약은 첫 방과 추가 19개를 합친 20개로 정의한다.

## 시간은 어떻게 확보하는가

공간을 2화면 길이로만 늘리면 플레이어가 달리기만 해 12분보다 훨씬 빨리 통과한다. 따라서 720초는 다음 요소가 만든다.

2차 실측에서 최고 속도 420px/s인 플레이어가 2,800px를 달리는 데 6.90초가 걸렸다. 이동 공격 19회를 섞어도 7.98초였다. 따라서 일반 공간 20초 중 순수 거리가 담당하는 비율은 약 34.5%이며, 나머지 13.10초는 아래의 실제 플레이로 구성한다.

| 20초 공간 구성 | 기준 시간 |
|---|---:|
| 직접 이동 | 6.9초 |
| 지형과 위험 읽기 | 2.6초 |
| 경로 선택 | 2.2초 |
| 상호작용 또는 전투 | 5.3초 |
| 착지·회복·출구 확인 | 3.0초 |

3차에서 위 기준을 6층 전체 좌표로 연결한 결과, 지형·전투가 없는 순수 이동 완주는 249.56초였다. 720초 목표까지 남은 470.44초는 36개 공간의 고유 플레이로 채운다. 이는 공간당 약 13.07초이며 2차의 13.10초 예산과 측정 오차 안에서 일치한다.

대형 월드는 36개 공간을 한꺼번에 처리하지 않는다. 1,400×900px 카메라 주위에 가로 700px·세로 350px의 준비 여백을 두고 최대 4개 공간만 활성화한다. 층 끝 이동은 1.4초 승강 과정으로 연결해 캐릭터와 카메라 좌표가 순간적으로 바뀌지 않게 한다.

- 지형을 읽고 안전 길과 빠른 길 중 선택하는 시간
- 시작 능력을 안전하게 교정하고 다음 능력을 예고하는 시간
- 최대 3체의 역할이 다른 적을 처리하는 시간
- 예고형 설비의 주기를 판단하는 시간
- 짧은 이야기 기록과 다음 목표 확인
- 수호자 전투와 보상·지름길 개방

강제 대기문, 긴 빈 복도, 같은 적 반복, 이유 없는 왕복으로 시간을 채우지 않는다.

## 실제 완주 시간 승인 기준

회색박스 전체가 연결되는 26차부터 시간을 실제로 측정한다.

| 대상 | 승인 범위 |
|---|---:|
| 첫 플레이 중앙값 | 11~14분 |
| 익숙한 플레이어 재도전 | 8~11분 |
| 길을 아는 빠른 플레이 | 최소 7분 |
| 개별 일반 공간 | 10~35초 |
| 수호자 2개 공간 합계 | 60~100초 |

빠른 플레이가 7분 아래로 내려가면 빈 거리를 늘리지 않고 선택·적 역할·복합 이동을 보강한다. 첫 플레이가 14분을 넘으면 반복, 불명확한 목표, 과도한 정밀 입력을 먼저 제거한다.

## 6층 지그재그

| 층 | 공간 | 진행 | 핵심 변화 |
|---:|---|---|---|
| 1층 | S01~S06 | 동쪽 | 이동·점프·안전한 낙하·첫 승강 |
| 2층 | S07~S12 | 서쪽 | 기본 공격 교정·첫 적·방패 적·정비축 |
| 3층 | S13~S18 | 동쪽 | 이동 발판·증기·세 역할 전투 |
| 4층 | S19~S24 | 서쪽 | 다음 스킬 잔향·상승 기류·비행 적·붕괴 교량 |
| 5층 | S25~S30 | 동쪽 | 기억 진실·압착기·복합 경기장·최종 휴식 |
| 6층 | S31~S36 | 서쪽 | 수호자 예고·2단계 전투·보상·출구 |

층 끝의 수직 연결은 동쪽과 서쪽을 번갈아 사용한다. `S06 동쪽 → S12 서쪽 → S18 동쪽 → S24 서쪽 → S30 동쪽` 순서다.

## 36개 공간 승인 규칙

모든 공간은 다음 내용을 데이터로 가진다.

1. 고유한 핵심 기능
2. 플레이어가 내리는 실제 선택
3. 실패했을 때 돌아오는 회수 경로
4. 이야기 또는 목표의 변화
5. 예상 시간과 긴장도
6. 필요한 경우 적의 역할과 최대 활성 수

어느 항목도 설명할 수 없는 구조물은 삭제한다. 강도 4 이상의 공간은 세 개 이상 연속 배치하지 않는다. 새 능력의 첫 시험에는 즉사 위험과 강제 전투를 넣지 않는다.

첫 초대형 방에서는 신규 스킬을 획득하지 않는다. 이동·가변 점프·공중 제어·기본 공격·상호작용을 시작 능력으로 사용하며, 첫 신규 이동 기능은 두 번째 초대형 방부터 획득한다. 과제나 몬스터가 있는 방은 완료 신호가 확인될 때까지 출구를 열지 않는다. 세부 승인 기준은 `quality-foundation.md`를 따른다.

## 체크포인트

`S01, S06, S12, S18, S24, S30, S35`에 체크포인트를 둔다. 한 층을 완료할 때마다 저장되며, 보스 직전과 보스 완료 뒤에도 별도 저장된다. 낙하나 패배로 이미 완료한 층 전체를 다시 걷게 하지 않는다.

4차에서 체크포인트는 각 지정 공간의 입구가 아니라 진행 방향 기준 출구 쪽에 실제로 배치했다. S06·S12·S18·S24·S30은 층 끝 승강기 직전, S35는 보상실을 통과한 뒤 활성화된다. 현재 진행 중인 층에서는 최대 한 층까지 다시 진행할 수 있지만 이미 완료한 이전 층은 반복하지 않는다.

브라우저 저장에는 체크포인트 ID·순서·스키마·빌드·체크섬만 기록하고 임의 좌표를 넣지 않는다. 손상된 JSON, 미래 버전, 존재하지 않는 ID는 S01 안전 기록으로 교체한다. 패배와 낙하 뒤 복귀는 약 0.7초의 전체 화면 페이드 안에서 수행한다.

## 이야기·목표·튜토리얼 안내

5차에서 첫 초대형 방의 프롤로그와 36개 공간별 이야기 단서를 실제 6층 런타임에 연결했다. 현재 목표는 11개 큰 단계에서만 바뀌며, 공간마다 메시지를 바꿔 플레이어의 시선을 과도하게 빼앗지 않는다.

이야기 배너는 5.25초 이내에 사라지고 대기열은 3개로 제한한다. `Tab` 기록창은 최근 6개만 보여주며 열어 둔 상태에서도 물리·입력·카메라가 계속 진행된다. 체크포인트 복원 시에는 저장된 임의 이야기 상태를 신뢰하지 않고 체크포인트 순서에서 이미 본 공간을 다시 파생한다.

S01~S06의 튜토리얼 순서는 이동, 가변 점프, 낮은 천장 아래 조기 해제, 안전 낙하와 공중 제어, 환경 신호 읽기, 승강기 상호작용으로 확정했다. 새 입력을 학습하는 공간에는 즉사 위험과 강제 전투를 넣지 않는다.
