# Coreless V4 재설계 4차 — 체크포인트와 안전한 저장·복귀

## 목적

첫 초대형 방에서 패배하거나 낙하했을 때 이미 완료한 층 전체를 다시 걷지 않도록 7개 체크포인트를 실제 6층 월드에 연결했다. 브라우저를 새로고침해도 진행 지점이 복원되며, 손상되거나 미래 버전인 저장 데이터는 안전한 S01로 되돌린다.

## 체크포인트 배치

| 체크포인트 | 위치 | 역할 |
|---|---:|---|
| S01 | 1층 시작 | 최초 안전 시작점 |
| S06 | 1층 동쪽 출구 | 1층 완료 저장 |
| S12 | 2층 서쪽 출구 | 2층 완료 저장 |
| S18 | 3층 동쪽 출구 | 3층 완료 저장 |
| S24 | 4층 서쪽 출구 | 4층 완료 저장 |
| S30 | 5층 동쪽 출구 | 5층 완료 저장 |
| S35 | 6층 보상실 출구 | 보스·보상 완료 저장 |

층 끝 공간에 들어오는 순간 저장하지 않고 실제 출구에 도달했을 때 저장한다. 따라서 저장만 활성화한 뒤 해당 층의 핵심 구간을 건너뛸 수 없다.

## 저장 안전성

저장 데이터에는 다음 다섯 항목만 기록한다.

- 스키마 버전
- V4 빌드 식별자
- 체크포인트 ID
- 체크포인트 순서
- 체크섬

플레이어 X/Y좌표를 저장하지 않는다. 복원 좌표는 검증된 체크포인트 정의에서 다시 계산하므로, 저장 파일을 잘못 수정해도 캐릭터가 벽이나 바닥 밖에서 생성되지 않는다.

다음 데이터는 모두 무효로 판단한다.

- JSON 문법이 손상된 저장
- 현재보다 높은 미래 스키마 버전
- 존재하지 않는 체크포인트
- ID와 순서·체크섬이 맞지 않는 저장

무효 저장은 삭제한 뒤 정상 S01 기록으로 교체한다. 브라우저 저장소에 접근할 수 없는 환경에서는 현재 세션의 메모리 저장으로 동작한다.

## 패배·낙하 복귀

- `K`: 패배 상황 시험
- `F`: 낙하 상황 시험
- `R`: 현재 체크포인트에서 재시작
- `C`: 저장 초기화

복귀는 0.45초 페이드 인과 0.25초 페이드 아웃으로 구성된다. 체크포인트 좌표로 바뀌는 순간에는 화면이 완전히 가려져 있으며, 일반 플레이 중 좌표 순간이동으로 처리되지 않는다.

체크포인트는 층 완료 단위이므로 보장 가능한 재진행 상한은 현재 진행 중인 한 층 16,800px다. 실제 낙하 시험에서 측정된 최대 재진행 거리는 3,640.75px였다. 완료한 이전 층은 다시 진행하지 않았다.
