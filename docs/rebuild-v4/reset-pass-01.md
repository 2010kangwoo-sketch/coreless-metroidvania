# Coreless V4 새 1차 — 첫 초대형 방 36공간 상세 설계

## 목적

새 40차의 첫 단계로 `M01 빈 제련소`의 36개 공간을 구현 전에 고정했다.
이번 차수는 회색박스·물리·전투·최종 그래픽을 만들지 않는다. 이후 차수에서
임의로 빈 복도나 의미 없는 발판을 추가하지 않도록 각 공간의 시간, 목적,
선택, 실패 회수, 필수 과제, 적, 이야기와 무전 위치를 먼저 계약한다.

## 1층 — 각성과 첫 교신

| 공간 | 시간 | 핵심 플레이 | 선택·회수 | 필수 완료 |
|---|---:|---|---|---|
| S01 빈 도착실 | 12초 | 좌우 이동과 동쪽 맥동 확인 | 꺼진 기록 단말 조사 가능, 위험 없음 | 좌·우 이동을 각각 확인 |
| S02 완만한 계단실 | 15초 | 짧은·긴 가변 점프 비교 | 계단 연속 점프 또는 긴 점프, 아래 회수 바닥 | 두 높이 표식 통과 |
| S03 압축 보수 통로 | 16초 | 점프 버튼 조기 해제 | 낮은 길 또는 기억 파편 선반, 천장 충돌도 안전 | 낮은 천장 구간 통과 |
| S04 완충 회수 우물 | 17초 | 낙하 중 공중 제어 | 중간 회수대 또는 바닥 직행, 비치명 완충 | 지정 착지 영역 도달 |
| S05 외곽망 유지보수실 | 16초 | 상호작용과 송수신기 획득 | 배전반·분리 레버 확인 순서 선택, 적 없음 | 전원→분리 레버→보관함 |
| S06 동부 중계 승강축 | 18초 | 첫 수직 이동과 마렌 교신 | 승강 중 자막 확인, 아래 안전대 | 중계 인증과 2층 도착 |

S01~S04에서는 실시간 대화가 없다. S05에서 보조 전원을 연결하고 고장 난
감시장치를 수동 분리한 뒤 `외곽망 현장 송수신기`를 얻는다. 공격을 배우기
전이므로 장치를 부수는 행동은 요구하지 않는다.

S06의 첫 교신:

> 마렌: 응답하세요. 제련소 내부에 누가 있습니까?
>
> 코어리스: 모르겠다.
>
> 마렌: 위치를 모른다는 뜻입니까, 이름을 모른다는 뜻입니까?
>
> 코어리스: ……둘 다.

승강기는 대화 중에도 움직이며 조작과 물리 시뮬레이션은 멈추지 않는다.

## 일반 적 5종

| 적 | 역할 | 플레이어 판단 |
|---|---|---|
| 제련 크롤러 | 지상 돌진형 | 긴 예고를 피하고 회복 시간에 반격 |
| 방패 파수기 | 전면 방어형 | 위 우회 또는 돌진 유도로 등 뒤 공격 |
| 비행 파수기 | 높이 압박형 | 낮은 엄폐와 높은 선제 위치 선택 |
| 고정 공명포 | 구역 통제형 | 예고선을 피해 이동하거나 전원 차단 |
| 공명 봉합체 | 지원형 | 보호막을 복구하기 전에 우선 처리 |

적은 최대 3체까지만 동시에 활성화한다. 숫자로 난도를 올리지 않고 서로
다른 역할을 조합해 판단을 요구한다.

## 필수 과제 잠금

23개 필수 과제 공간은 완료 전까지 출구가 열린 것처럼 보이지 않는다.
보이지 않는 벽 대신 문양, 조명, 문 구조, 기계 반응으로 잠긴 이유를
표시한다.

실패하면 현재 공간의 비어 있는 입구 안전대에서 다시 시작하며, 이미
완료한 이전 층으로 돌려보내지 않는다. 일반 이동 공간은 별도의 강제
대기문을 사용하지 않는다.

## 1차에서 의도적으로 하지 않은 것

- 실제 지형과 충돌 구현
- 이동 수치 변경

- 최종 그래픽과 애니메이션

이 항목들은 승인된 상세 설계를 기준으로 뒤 차수에서 하나씩 구현한다.
