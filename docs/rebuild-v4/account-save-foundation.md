# V4 계정·클라우드 저장 기반 복구본

## 현재 실제 작동

- 시작 화면의 `계정 및 저장`
- 브라우저마다 한 번 생성되는 게스트 신원
- 게스트 체크포인트 로컬 저장
- 새로고침 후 동일 게스트 유지
- Google, 카카오, Facebook, 네이버 로그인 항목 표시
- 최종 사이트 주소가 없는 동안 공급자 버튼 비활성화

## 최종 주소 확정 후 활성화

- Auth.js 기반 네 공급자 OAuth 로그인
- PostgreSQL 사용자·계정·세션·게임 저장
- 로그인 직후 게스트 기록의 클라우드 이전
- 로그인 상태의 체크포인트 자동 저장
- 다른 기기의 클라우드 기록 복구
- local/cloud 기록 차이와 revision 충돌 시 사용자 선택

비밀키와 공급자 토큰은 브라우저나 GitHub에 저장하지 않는다. `.env`는
Git에서 제외한다.
