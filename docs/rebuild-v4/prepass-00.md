# Coreless V4 새 40차 0차 준비 — 제작 기준 고정

## 이번 단계의 성격

이 문서는 새 1차를 시작하기 전의 0차 준비 계약이다. 기존 V4 1~5차와
V2·V3 결과를 완성된 새 차수로 계산하지 않는다. 기존 구현은 실험 자료로
보존하며, 새 계약을 다시 통과한 부분만 재사용한다.

새 40차의 목적은 4시간 분량 전체 게임을 한 번에 완성하는 것이 아니다.
게임 시작부터 튜토리얼과 첫 초대형 방 `M01 빈 제련소`의 출구까지를 출시
후보 수준으로 완성하고, 나머지 19개 초대형 방을 같은 품질로 제작할 기반을
확립하는 것이다.

## 최종 범위

| 구분 | 기준 |
|---|---|
| 전체 캠페인 | 20개 초대형 방 |
| 전체 목표 시간 | 약 240분 |
| 이번 40차 실제 구현 | 프롤로그·튜토리얼·M01 |
| M01 규모 | 6층·36공간 |
| M01 첫 플레이 목표 | 11~14분 |
| M01 신규 스킬 | 없음 |
| 첫 신규 스킬 | M02 냉각 수로의 공명 날개 |
| 시작 능력 | 이동·가변 점프·공중 제어·기본 공격·상호작용 |
| 최종 실행 | 사이트 접속 후 시작 화면에서 바로 플레이 가능 |

`첫 초대형 방 + 추가 19개 = 총 20개`를 기준으로 한다. 첫 방 뒤에 20개를
더 만드는 21개 구성이 아니다.

## 0차에서 확정한 이야기

코어리스는 원점 코어의 최후 연결사였다. 도시 전체의 기억이 강제로
융합되는 폭주를 멈추기 위해 자신의 중심을 직접 분리해 원점의 봉인에
사용했다. 분리된 중심은 철수자들의 공포와 수호 명령을 계속 받아들이며
검은 공명이 됐다.

원점은 코어리스를 부르면서도 자신을 다시 버릴까 두려워 수호자와 시설을
움직여 공격한다. 마지막 목표는 단순히 악을 파괴하는 것이 아니라, 기억을
지우지 않은 채 분리된 중심과 다시 연결하고 그 결과를 감당하는 것이다.

세부 캠페인 전개와 장면은 `story-bible.md`를 따른다.

## 0차에서 확정한 무전기

주인공은 처음부터 무전기를 가지지 않는다.

1. S01~S04는 실시간 대화 없이 혼자 움직이며 기본 조작을 익힌다.
2. S05 유지보수실에서 보조 전원을 연결하고 감시장치를 제거한다.
3. 필수 과제를 완료한 뒤 비상 보관함에서 `외곽망 현장 송수신기`를 얻는다.
4. S06의 안전한 승강축 발판에서 외곽 관측원 마렌과 처음 교신한다.

마렌은 살아 있는 현재 인물이고, 에인은 폭주 당시의 손상된 기록이다.
원점은 코어리스에게서 분리된 중심이다. 세 목소리를 같은 존재처럼
처리하지 않는다.

무전은 조작을 멈추지 않는다. 정밀 이동·전투·추격 중 긴 대화는 안전
구간까지 보류하고 자막은 한 번에 두 줄까지만 표시한다. 마렌은 퍼즐의
정답이나 내부의 모든 사실을 알지 못한다.

## 기존 자료 처리

### 유지하되 새로 검증

- 36공간·6층 규모 데이터
- 대형 월드 스트리밍과 감쇠 카메라 실험
- 체크포인트와 좌표가 아닌 공간 단위 저장
- 게스트 신원과 브라우저 로컬 저장
- 최종 주소와 비밀키가 준비된 뒤 활성화할 OAuth 서버 기반
- 방 완료 잠금, 지형, 추격, 모션, 수동 승인 품질 계약

### 새 차수에서 다시 작성

- 기존 차수 번호와 완료 주장
- 프롤로그와 36개 공간의 이야기 문장
- S05 무전기 획득과 S06 첫 교신
- 튜토리얼 실제 지형과 최종 조작 수치
- 모든 방의 지형·전투·몬스터·보스·최종 아트

### 기록으로만 보존

- V2·V3 직선형 장거리 경로
- 기존 40차의 완성 아트 구간
- 폐기된 구조만 통과했음을 증명하는 검사 결과

이미 존재한다는 이유만으로 코드를 승인하지 않는다. 재사용하는 기능도
새 계약과 현재 실제 플레이 검사를 다시 통과해야 한다.

## 36공간의 서사 역할

| 층 | 공간 | 진행 | 핵심 역할 |
|---:|---|---|---|
| 1층 | S01~S06 | 동쪽 | 각성·기본 이동·송수신기 획득·첫 교신 |
| 2층 | S07~S12 | 서쪽 | 기본 공격 교정·첫 적·침입자 판정 |
| 3층 | S13~S18 | 동쪽 | 제련 기능·철수 흔적·역할형 전투 |
| 4층 | S19~S24 | 서쪽 | M02 스킬 예고·상승 기류·붕괴·생체 오염 |
| 5층 | S25~S30 | 동쪽 | 중심 분리 단서·복합 전투·보스 전 휴식 |
| 6층 | S31~S36 | 서쪽 | 규칙 학습·제련 수호자·보상·다음 방 |

새 1차에서는 위 역할을 바탕으로 S01~S36 각각의 목적, 예상 시간, 선택,
회수 경로, 필수 과제, 적, 이야기, 무전 여부를 하나의 표로 작성한다.

## 완료를 막는 항목

다음 항목이 하나라도 존재하면 자동 검사가 통과해도 해당 차수를 완료하지
않는다.

- 임무가 있는 방을 완료하지 않고 출구를 통과할 수 있음
- 도달할 수 없거나 목적이 없는 충돌 바닥이 존재함
- 캐릭터를 갑자기 위나 옆으로 옮기는 좌표 보정이 존재함
- 벽을 비비기만 해도 자동으로 올라감
- 가파른 경사에서 한 입력마다 크게 튀거나 미끄럼 규칙이 불명확함
- 추격 물체가 바닥 아래나 플레이어와 겹쳐 생성됨
- 긴 무전이 정밀 이동·전투·추격 입력을 방해함
- 전경 그림과 실제 충돌 지형이 다름
- 다리와 기둥의 아래쪽이 허공에서 잘려 보임
- 같은 지형·몬스터·구조 역할이 연속 반복됨
- 콘솔 오류나 페이지 오류가 발생함
- 기존 실험 코드를 현재 검사 없이 그대로 승인함

## 수동 승인

10차·20차·30차·40차는 자동 검사만으로 완료할 수 없다.

- 10차: 기본 이동과 고독한 튜토리얼
- 20차: 1~3층의 조작·전투·공간 다양성
- 30차: 36공간 전체 회색박스와 11~14분 시간
- 40차: 시작 화면부터 M01 출구까지 최종 출시 후보

사용자 실제 플레이에서 불친절함, 부자연스러운 움직임, 반복, 이유 없는
구조물이 발견되면 해당 차수로 돌아가 수정한다.

## 0차 완료 조건

- 제품 범위가 첫 초대형 방 출시 후보로 한정됨
- 전체 캠페인은 20개·4시간으로 유지됨
- 이야기의 핵심 진실과 결말이 고정됨
- 마렌·에인·원점의 역할이 분리됨
- 송수신기 획득 위치와 첫 교신 위치가 고정됨
- 기존 구현의 유지·재작성·기록 전용 범위가 구분됨
- 새 1~40차의 작업 순서와 승인 조건이 존재함
- 위 항목을 검사하는 결정적 검증기가 CI에 포함됨
