# Coreless V4 재설계 3차 — 대형 월드 카메라와 공간 스트리밍

## 목적

첫 초대형 방의 16,800×7,400px 전체 크기를 실제 런타임 좌표로 만들고, 6개 층을 동·서 방향으로 번갈아 이동할 때 카메라와 공간 활성화가 끊기지 않는지 검증했다. 이번 차수는 최종 지형이나 그래픽을 만드는 단계가 아니라, 이후 36개 공간을 안전하게 얹을 대형 월드 기반을 고정하는 단계다.

## 구현한 기반

- 6층 × 6공간 = 36개 실제 월드 구역
- 층당 16,800px 연속 가로 경로
- 진행 방향: 동·서·동·서·동·서
- 층 간격: 1,200px
- 층 끝 승강기: 1.4초 연속 이동
- 카메라 해상도: 1,400×900px
- 가로·세로 추종 속도 분리
- 원경·중경 시차 비율 분리
- 카메라 주변 공간만 활성화
- 동시 활성 공간 상한: 4개

승강기는 캐릭터 좌표를 다음 층으로 바꾸지 않는다. 120Hz 물리 프레임마다 약 7.14px씩 실제로 이동하며, 카메라는 더 느린 반응으로 이를 따라간다.

## 전체 경로 측정

| 항목 | 결과 |
|---|---:|
| 순수 이동 완주 시간 | 249.56초 |
| 목표 초대형 방 시간 | 720초 |
| 이후 설계가 채워야 할 시간 | 470.44초 |
| 층 전환 | 5회 |
| 방문 공간 | 36/36 |
| 불러온 공간 | 36/36 |
| 동시 활성 공간 | 최대 4개 |
| 최종 활성 공간 | 2개 |
| 공간 로드/해제 | 61/59회 |
| 빈 스트리밍 프레임 | 0 |
| 전체 물리 프레임 | 30,006 |

순수 이동은 약 4분 10초다. 따라서 12분 목표를 맞추려면 약 7분 50초를 구조와 플레이가 담당해야 한다. 빈 복도나 강제 대기가 아니라 2차에서 정한 공간별 지형 읽기·경로 선택·상호작용/전투·회복 예산으로 채운다.

## 검사 결과

### 정적 구조 검사

- 통과: 30/30
- 이전 1·2차 검사 유지
- 36개 구역의 연속 배치 확인
- 모든 구역 중심에서 스트리밍 보장
- 카메라·시차·승강 시간 상한 확인

### 실제 브라우저 검사

- 통과: 28/28
- 실제 `D` 2.2초 입력에서 플레이어 위치 947.75px
- 실제 가로 카메라 최대 이동 3.48px/프레임
- 실제 `A/D/E` 키 상태로 6층 전체 경로 진행
- 플레이어 최대 이동 7.14px/프레임
- 카메라 최대 이동 7.13px/프레임
- 좌표 순간이동·빈 스트리밍·콘솔 오류: 0

초기 구현에서는 승강 시작 순간 레일 중심으로 X좌표를 141px 보정하는 문제가 검출됐다. 이 실행은 실패로 처리했다. 수정 후에는 층 끝에 물리 이동으로 멈추고 승강 중 X좌표를 바꾸지 않도록 했으며, 전체 검사를 다시 통과했다.
