# Coreless V4 재설계 1차 — 12분 초대형 방 규모 확정

## 완료한 작업

기존 V3의 15개 공간 기준을 폐기하지 않고 기록으로 보존한 뒤, 새 V4 브랜치에서 초대형 방 규모를 다시 정의했다.

- 첫 초대형 방: 36개 공간
- 실제 층: 6층
- 층당 공간: 6개
- 진행 방향: 동·서 교대
- 공간 크기: 약 2화면
- 평균 목표 시간: 20초
- 첫 방 목표 시간: 720초
- 기준 월드: 16,800 × 7,400px
- 체크포인트: 7개
- 공간 역할 종류: 13종
- 전체 캠페인: 20개 초대형 방·720공간·4시간

## 첫 방의 리듬

1. S01~S06: 안전한 이동, 점프 높이, 낙하 회수, 첫 층 전환
2. S07~S12: 절단 권한 회수, 첫 크롤러, 방패 파수기
3. S13~S18: 이동 발판, 증기, 처리 순서를 고르는 세 역할 전투
4. S19~S24: 공명 날개 회수, 이중 점프, 비행 파수기, 붕괴 교량
5. S25~S30: 분리 기록, 압착기, 역행 운반대, 혼성 경기장
6. S31~S36: 수호자 예고, 2단계 제련 수호자, 보상과 지름길

공격 획득 전에는 강제 전투가 없다. 이중 점프를 얻는 S19와 첫 시험 S20에는 피해 요소가 없다. 동시에 활성화되는 적은 최대 3체다.
