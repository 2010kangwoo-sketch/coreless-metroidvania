# Coreless V4 출시 목표 새 1차

## 결과

전체 20개 초대형 방의 능력 선행관계·공간 정체성·절정 유형·이야기 공개·다음
목표를 고정했다. M01 `빈 제련소`의 36개 공간은 여덟 개 공간 설계 축과
필수 이동 여유 수치를 각각 가지도록 정리했다.

이번 차수는 설계 차수다. 기존 이동·충돌·전투·카메라 런타임과 최종
그래픽은 수정하지 않았다.

## M01 36공간 설계 축

각 공간은 다음 여덟 축을 모두 가진다.

1. 실루엣
2. 진행 방향
3. 높이 변화
4. 중심 구조물
5. 이동 리듬
6. 위험 또는 적 역할
7. 조명과 배경 깊이
8. 이야기 목적

인접 공간은 최소 세 축이 다르다. 각 층에는 최소 네 종류의 실루엣,
세 종류의 이동 리듬, 세 종류의 중심 구조물이 포함된다.

| 층 | 공간 | 실루엣 예시 | 주요 리듬 | 고강도 이후 회수 |
|---:|---|---|---|---|
| 1 | S01~S06 | 도착실·계단·압축 통로·우물·작업실·승강축 | 관찰·점프 비교·낙하·상호작용·교신 | 완충 바닥과 안전대 |
| 2 | S07~S12 | 갈비 회랑·교정실·화덕 둥지·운반교·전투 둥지·정비축 | 경로 비교·공격 교정·첫 전투·탑승·우회 | 후퇴대와 중간 홈 |
| 3 | S13~S18 | 주조장·환기실·기중기 교차장·증기 수로·전투뜰·승강고 | 점프 선택·봉쇄·주기 관찰·우선순위 전투 | 경사 회수면과 안전 승강고 |
| 4 | S19~S24 | 제단·상승 우물·분기 공방·온실·교량·회수로 | 분석·부유·경로 선택·공중전·붕괴 | 보수 통로와 휴식대 |
| 5 | S25~S30 | 기억못·압착실·용광로 늑골·운반 회랑·경기장·휴식 승강고 | 기억·타이밍·곡선 이동·역행·혼성 전투 | 안전대·하부 통로·체크포인트 |
| 6 | S31~S36 | 전실·외곽 고리·심장실·공명 격실·회수실·전망 출구 | 관찰·예행·보스 2막·보상·조망 | 반격 창·하부 바닥·영구 출구 |

## 조작 여유

- 일반 필수 이동 최대 도달 비율: 80% 이하
- 어려운 필수 이동 최대 도달 비율: 88%
- 일반 착지면 최소: 플레이어 몸 폭 2.2배
- 정밀 착지면 최소: 플레이어 몸 폭 1.65배
- 한 공간의 정밀 착지 연속: 최대 2회
- 모든 필수 도착 지점은 도약 전에 확인 가능
- 모든 공간에 회수 바닥, 후퇴대, 안전 홈, 체크포인트 중 하나 이상 존재
- 한 프레임 입력과 숨은 자동 보정은 사용하지 않음
