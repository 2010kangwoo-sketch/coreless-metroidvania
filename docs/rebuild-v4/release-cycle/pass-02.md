# Coreless V4 출시 목표 새 2차

## 결과

1차에서 확정한 M01 설계에 출시판 지상 이동 기준선을 연결했다. 과거 reset
2차 모듈의 수치를 복사하거나 다시 조정하지 않고, 검증된 모듈을 새 출시
사이클에서 직접 실행해 결정적 검사와 실제 키보드 검사를 다시 통과시켰다.

이번 차수는 달리기·정지·방향 전환만 완료한다. 짧은·긴 점프, 코요테 타임,
착지 입력 버퍼는 3차 완료 조건이며 이번 차수의 완료 수에 포함하지 않는다.

## 확정 수치

| 항목 | 출시판 기준 | 결정적 측정 |
|---|---:|---:|
| 최고 지상 속도 | 400px/s | 400px/s |
| 최고 속도 90% 도달 | 0.12~0.20초 | 0.150초 |
| 90% 도달 거리 | 24~36px | 27px |
| 입력 해제 후 정지 | 0.10~0.16초 | 0.125초 |
| 정지 거리 | 20~30px | 25px |
| 반대 방향 90% 도달 | 0.16~0.24초 | 0.192초 |
| 전환 중 전방 밀림 | 15~24px | 19.021px |
| 지형 전환 여유 | 최소 3 몸 폭 | 120px |
| 전환 후 남는 회수 여유 | 최소 2 몸 폭 | 100.979px |

## 이전 클레임 반영

- 방향 전환 직후 벽이나 장애물에 끼지 않도록 전환 지형에 최소 120px를 둔다.
- 입력을 놓은 뒤 25px 안에 멈춰 착지 직후 과도하게 미끄러지지 않는다.
- 가속과 방향 전환을 서로 다른 수치로 유지해 출발은 부드럽고 반전은 빠르게 한다.
- A/D와 방향키 입력을 모두 브라우저에서 직접 발생시켜 검사한다.
- 1차의 일반 필수 이동 80% 상한과 일반 착지면 2.2 몸 폭 기준을 함께 회귀 검사한다.
- 숨은 위치 보정이나 경계 강제 이동을 성공 근거로 사용하지 않는다.

## 검사

결정적 검사는 `tools/verify-rebuild-v4-release-pass02.mjs`, 실제 키보드
브라우저 검사는 `tools/verify-rebuild-v4-release-pass02-browser.mjs`가 맡는다.

브라우저 검사는 실제 `keydown`·`keyup`으로 가속 3회, 정지 3회, 방향 전환
1회를 측정하며 다음도 함께 확인한다.

- 지상 이동 상태 5종이 모두 발생
- 위치 갱신 한 프레임 최대 3.4px
- 경계 보정 및 초기화 사용 0회
- 콘솔 오류 및 페이지 오류 0개
