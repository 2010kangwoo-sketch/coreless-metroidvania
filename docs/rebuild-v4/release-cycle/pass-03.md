# Coreless V4 출시 목표 새 3차

## 결과

2차에서 확정한 지상 이동에 가변 점프, 공중 제어, 코요테 타임, 착지 입력
버퍼를 연결했다. 과거 reset 3차의 검증된 물리 모듈을 수정하지 않고 출시판
전용 시험장에서 결정적 검사와 실제 키보드 검사를 다시 수행했다.

이번 차수에는 이중 점프와 대시를 넣지 않는다. 입력 관용성은 실수를 조금
받아주는 역할만 하며, 숨은 위치 이동이나 자동 턱넘기로 진행을 대신하지 않는다.

## 점프 거리와 장애물 여유

최고 지상 속도에서 출발해 Space를 유지한 점프의 수평 도달 거리는
266.146px이다.

| 구분 | 최대 사용 비율 | 필수 지형 상한 | 남는 여유 |
|---|---:|---:|---:|
| 일반 필수 이동 | 80% | 212.917px | 53.229px |
| 어려운 필수 이동 | 90% | 239.531px | 26.615px |
| M01 현재 고난도 최대 | 88% | 234.208px 상당 | 31.938px 상당 |

거리 상한만 맞추는 것으로 완료하지 않는다. 도약 전에 목적지를 볼 수 있어야
하고, 일반 착지면은 2.2 몸 폭 이상, 정밀 착지면은 1.45 몸 폭 이상이어야
한다. 정밀 착지를 세 번 이상 연속시키지 않는다.

## 실제 키보드 검사

`tools/verify-rebuild-v4-release-pass03-browser.mjs`가 실제 `keydown`과
`keyup`으로 다음 순서를 재현했다.

1. Space를 짧게 눌러 짧은 점프 측정
2. Space를 정점까지 유지해 긴 점프 측정
3. 공중에서 Space를 다시 눌러 이중 점프가 생기지 않는지 확인
4. D+Space 상승 중 A로 바꿔 공중 반전 확인
5. 발판을 벗어난 뒤 Space를 눌러 코요테 점프 확인
6. 착지 직전 Space를 눌러 버퍼 점프 1회 확인

실제 키 측정에서는 짧은 점프 78.584px, 긴 점프 139.417px, 공중 반전
250px/s에서 -225px/s, 코요테 점프 1회, 버퍼 점프 1회를 기록했다.
경계 강제 보정과 초기화 사용은 0회였고 콘솔·페이지 오류도 없었다.
