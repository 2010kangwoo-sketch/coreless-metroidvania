## 출시 목표 범위

이번 40차는 프로토타입이나 기능 시연본이 아니라 브라우저에서 바로 실행하고
처음부터 끝까지 플레이할 수 있는 출시 후보를 만든다.

- 전체 캠페인: 초대형 방 20개, 약 4시간
- 이번 40차 실제 완성 범위: `M01 빈 제련소`
- M01: 6층, 36공간, 목표 약 12분
- M02~M20: 전체 진행·능력·스토리 계약까지만 확정
- 첫 신규 주요 능력: `M02 냉각 수로`
- M01에서는 신규 주요 능력을 지급하지 않음

나머지 19개 초대형 방을 미완성 런타임으로 억지로 채우지 않는다. M01과
공통 시스템을 출시 가능한 수준으로 완성한 뒤 같은 제작 체계로 확장한다.

## 장애물 여유 계약

난도는 최대 점프 거리와 한 프레임 입력을 강요해서 만들지 않는다.

| 항목 | 기준 |
|---|---:|
| 일반 필수 이동 | 검증된 최대 도달 성능의 80% 이하 |
| 어려운 필수 이동 | 검증된 최대 도달 성능의 90% 이하 |
| 숙련 선택 도전 | 최대 96%, 필수 진행에 사용 금지 |
| 일반 착지면 | 플레이어 몸 폭 2.2배 이상 |
| 정밀 착지면 | 플레이어 몸 폭 1.45배 이상 |
| 정밀 착지 연속 | 최대 2회 |
| 위험 예고 | 최소 0.55초 |
| 실패 후 재시작 | 최대 0.7초 |

추가 규칙:

1. 필수 점프는 도약 전에 목적지 또는 안전한 착지 방향을 볼 수 있어야 한다.
2. 고강도 공간 뒤에는 관찰, 회복, 안전 이동 중 하나를 둔다.
3. 작은 실수 한 번이 항상 즉사로 이어지지 않게 회수 바닥이나 후퇴 공간을 둔다.
4. 숨은 위치 보정, 자동 벽타기, 자동 턱넘기로 성공을 대신하지 않는다.
5. 실제 키보드 플레이에서 불친절하거나 빡빡하면 자동 검사가 통과해도 실패다.

## 공간 다양성 계약

36개 공간은 모두 다음 여덟 축으로 지형 서명을 가진다.

1. 전체 실루엣
2. 주 진행 방향
3. 높이 변화
4. 중심 구조물
5. 이동 리듬
6. 장애물 또는 적 역할
7. 조명과 배경 깊이
8. 이야기 목적

적용 기준:

- 36개 공간 모두 고유한 지형 서명 사용
- 인접 공간은 여덟 축 중 최소 세 축이 달라야 함
- 층마다 최소 네 종류의 실루엣 사용
- 층마다 최소 세 종류의 이동 리듬 사용
- 층마다 최소 세 종류의 중심 구조물 사용
- 동일한 고강도 리듬은 최대 두 공간까지만 연속
- 같은 구조를 크기나 색만 바꿔 반복하는 방식 금지
- 의미 없는 충돌 구조물과 도달 불가능한 보행면 금지
- 다리와 기둥의 지지대가 허공에서 끝나는 형태 금지

공간이 서로 달라도 같은 세계로 보이도록 재질, 공명 문양, 구조 결합 방식,
팔레트와 조명 원리는 공유한다.

## 출시 후보 완료 조건

40차 완료를 선언하려면 다음 조건을 모두 만족해야 한다.

- 시작 화면부터 M01 출구까지 실제 키보드 무중단 완주
- 좌표 주입을 완주 증거로 사용하지 않음
- 진행 불가능 오류 0개
- 콘솔 오류 0개
- 페이지 오류 0개
- 체크포인트와 저장 복원 정상
- 최종 화면에 회색 충돌 블록이나 임시 그래픽 없음
- 캐릭터, 적, 환경의 화풍과 명암 언어 통일
- 목표 60fps, 무거운 장면 최소 50fps
- 브라우저에서 별도 설치 없이 즉시 실행
- 사용자 최종 플레이 승인

자동 검사는 필요한 증거지만 출시 승인을 대신하지 않는다.

## 차수 운영

- 새 차수는 이전 차수의 실제 실행과 회귀 검사를 먼저 수행한다.
- 완료 조건이 실패하면 차수 번호를 올리지 않는다.
- 구현 차수마다 실제 키 입력, 결정적 검사, 브라우저 화면 검사를 구분한다.
- 완료 차수마다 커밋 SHA와 검증된 번들이 있어야 한다.
- 10·20·30·40차에는 사용자 실제 플레이 승인을 받는다.
- `main`에는 병합하지 않는다.
