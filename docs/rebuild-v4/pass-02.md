# Coreless V4 재설계 2차 — 실제 이동과 20초 공간 예산

## 목적

1차에서 정한 “공간 하나는 화면 약 2배, 평균 20초”가 실제 조작 속도에서도 성립하는지 측정했다. 빈 길이를 늘리는 방식으로 12분을 만들지 않기 위해, 아무 장애물이 없는 2,800px 바닥과 이동 중 공격 조건을 각각 실제 키보드 입력으로 완주했다.

## 확정한 이동 기준

| 항목 | 측정값 |
|---|---:|
| 최고 달리기 속도 | 420px/s |
| 2,800px 단순 달리기 | 6.90초 |
| 이동 공격 19회 포함 | 7.98초 |
| 짧은 점프 높이 | 83.90px |
| 긴 점프 높이 | 133.65px |
| 최고속도 반전 | 0.425초 |
| 최고속도 정지 | 0.133초·25px |
| 플레이어 최대 프레임 이동 | 3.5px |
| 카메라 최대 프레임 이동 | 3.5px |

기본 공격은 0.34초 주기이며 공격 중 이동 속도를 82%까지 유지한다. 따라서 공격 때문에 캐릭터가 제자리에 고정되거나 반복 입력마다 멈추지 않는다.

## 20초 공간 시간 배분

단순 달리기 6.90초는 목표 20초의 34.5%다. 나머지 13.10초는 다음과 같이 설계한다.

| 역할 | 시간 |
|---|---:|
| 지형과 위험 읽기 | 2.6초 |
| 안전 길·빠른 길 선택 | 2.2초 |
| 고유 상호작용 또는 전투 | 5.3초 |
| 착지·회복·출구 확인 | 3.0초 |
| 합계 | 13.1초 |

이 시간은 강제 대기문, 의미 없는 경사로, 같은 장애물 반복으로 채우지 않는다. 각 공간에는 읽기·선택·상호작용 중 최소 하나가 실제 플레이 규칙으로 존재해야 한다.
